一键启动

默认本地模式，零 API Key，30 秒跑起来。

git clone https://github.com/xingjianlu573-dot/dianshanznkf.git
cd dianshanznkf
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
uvicorn api:app --port 8010
# 打开 http://localhost:8010

想接国产大模型：复制 .env.example 为 .env， 设置 MODEL_PROVIDER=deepseek 并填 DEEPSEEK_API_KEY 即可。
